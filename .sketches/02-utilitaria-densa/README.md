# Variante 02 — Utilitaria Densa (Stripe × Linear)

## Stance
Landing que se lee como un **producto técnico**, no como una tienda. Code panel con ejemplo real de API, métricas trimestrales tipo dashboard, tabla de precios funcional, navegación estilo docs. Habla a gente que evalúa si vale la pena integrarlo o comprarlo en volumen.

## Decisiones clave
- **Layout:** grids densos de 12 columnas, hero split 60/40 con code panel a la derecha
- **Tipografía:** Inter para todo, JetBrains Mono para datos y code blocks
- **Color:** zinc neutro + emerald como accent funcional (botones primarios, badges)
- **Elementos diferenciales:**
  - Banner superior tipo "changelog" con versión
  - Code panel con syntax highlight mostrando cómo se crea un pedido por API
  - Stats table con datos trimestrales reales (Q1/Q2/Q3 con indicadores)
  - Pricing con 3 tiers y el "Más elegido" como ancla visual
- **Sin animaciones decorativas** — todo es información

## Trade-offs
- ✅ Comunica seriedad técnica, apto para B2B y revendedores
- ✅ El code panel da una razón concreta para probar
- ⚠️ Más frío que el editorial; menos aspiracional
- ⚠️ Requiere datos reales cuando se vaya a producción (la tabla de stats hoy muestra ejemplos)

## Mejor para
Clientes B2B, mayoristas, gente que evalúa volumen. Equipos que quieren sentirse comprando un servicio, no un regalo.
