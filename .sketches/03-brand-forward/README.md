# Variante 03 — Brand Forward (conversacional)

## Stance
Landing que se siente como **la home de una marca, no la home de un e-commerce**. Mockup de producto enorme, mucho whitespace, eyebrow chip verde, tagline grande con serif itálica, manifiesto en bloque emerald. Habla a una persona, no a un segmento.

## Decisiones clave
- **Layout:** todo a una columna, centrado, con respiración generosa (140px entre secciones)
- **Tipografía:** Playfair Display para titulares + Inter para UI
- **Color:** fondo cálido (`#fafaf9`), zinc casi negro para texto, emerald como única chispa
- **Mockup display:** termo grande con 3 floating tags mostrando datos del producto, sin foto real (silueta CSS)
- **Manifiesto en bloque emerald** — distinto al típico CTA blanco
- **Sin grid de cards repetidas** — los productos son 3 piezas individuales con su propio bloque

## Trade-offs
- ✅ Se siente curado, no automático
- ✅ El mockup display le da protagonismo al producto sin necesitar fotografía profesional todavía
- ⚠️ El hero es 100% texto + 1 imagen — menos "información densa"
- ⚠️ Pieza demasiado centrada: si después se agrega mucha copy por producto, hay que romperla

## Mejor para
Cuando la marca y el equipo son parte del producto (Luis, fundador). Consumidores finales que se enamoran antes de comprar. Regalos personalizados.
