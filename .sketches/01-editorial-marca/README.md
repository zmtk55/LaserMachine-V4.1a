# Variante 01 — Editorial Marca

## Stance
Landing con personalidad de **estudio de grabado**, no de e-commerce. Mucho aire, tipografía serif itálica para la voz de marca, inter sans para datos y UI. Habla como un artesano que sabe lo que hace.

## Decisiones clave
- **Layout:** grid 12-col asimétrico (4+5 / 5+7 en catálogo); artefacto hero a la derecha con formato "ficha técnica", no foto de stock
- **Tipografía:** Playfair Display itálica para titulares y manifiesto; Inter para UI; JetBrains Mono para datos
- **Color:** zinc-900 base + emerald-700 como único accent (cero amarillo/amber/orange). El manifesto y CTA final van en zinc-900 con tipografía blanca
- **Interacción:** FAQ con toggle real, sin animaciones decorativas
- **Copy:** prosa, no slogans. Primera persona del plural, tono estudio argentino

## Trade-offs
- ✅ Se aleja totalmente del "AI landing template" — no hay blobs, no hay card grid de 3 idénticas
- ✅ La ficha técnica a la derecha comunica producto sin tener que inventar fotos
- ⚠️ El hero es más denso en texto, menos "wow visual" instantáneo
- ⚠️ Requiere buenas fotos de producto cuando se vaya a producción (los silhouettes son placeholder)

## Mejor para
Clientes que valoran oficio y durabilidad sobre precio. Marca personal de fundador, no marca blanca.
